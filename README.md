# AetherChat · 灵语（国服 Dalamud 插件）

接收已开启频道中的其他玩家消息，调用本机或云端 AI，再让当前登录的角色在原频道回复。悄悄话始终回复该条消息的原发件人，不使用可能已改变对象的 `/reply`。

发布维护者可参阅 [GitHub 第三方库发布说明](PUBLISHING.md)。正式库地址将在完成 GitHub 发布后添加；目前请按下方开发插件方式加载。

## 当前版本与验证范围

- 版本：0.1.1，Windows x64、Dalamud API 15、.NET 10。
- 已使用本机国服 Dalamud **15.0.3.6** 程序集编译，零警告、零错误。
- 29 项自动测试覆盖关键词、五频道路由、私聊隔离、取消、限流、UTF-8、三种 API 格式、DPAPI、本机模拟 HTTP 往返和跨服队伍判断；运行结果见 `VALIDATION.md`。
- 用户已确认可以取得 DeepSeek 回复，说话频道正常；0.1.1 修复后，**副本外跨服小队已由用户实测成功**。GPT、Claude 实际服务及其他未测频道不作已验证声明。
- 这是本地开发加载版本，没有发布到插件仓库，也不会自动安装或修改启动器配置。游戏更新或 Dalamud API 升级后可能需要重新编译。

## 安装和第一次使用

1. 将 `AetherChat-0.1.1.zip` 解压到一个固定目录。也可以直接使用本项目 `dist/0.1.1` 目录。保持这四个文件在一起：`AetherChat.dll`、`AetherChat.Core.dll`、`AetherChat.deps.json`、`AetherChat.json`。
2. 在已启用 Dalamud 的国服游戏中输入 `/xlsettings`，打开实验性设置，找到开发插件路径（Dev Plugin Locations），添加解压目录内 **AetherChat.dll 的完整路径**，启用并保存。
3. 输入 `/xlplugins`，在开发插件区域扫描并加载 `AetherChat · 灵语`。界面名称可能随国服启动器版本变化。
4. 输入 `/aichat` 打开面板，到“模型连接”选择配置，填写基础地址、模型 ID；云端填入 API Key 并点“保存密钥”。
5. 点击“测试连接”，结果只显示在插件面板，不向游戏频道发消息。
6. 到“频道与关键词”开启要回复的频道，设置关键词。打开 AI 总开关，开始接收他人消息。

加载插件后 AI 总开关默认关闭；全部频道初始也关闭。频道选择会保存，总开关不保存；退出角色后关闭，需要重新开启。

## 从 0.1.0 更新

1. 关闭 AI，在 `/xlplugins` 禁用灵语。
2. 在 `/xlsettings` 的开发插件路径中，将原来的 AetherChat 路径修改为新目录里的 `AetherChat.dll`。不要同时保留两份启用的灵语路径。
3. 回到 `/xlplugins`，重新扫描并加载。面板标题应显示 **0.1.1**。插件名称与配置格式不变，仍读取原来的模型、密钥和频道设置。
4. 确认“仅预览”关闭，打开 AI 总开关与“小队”；让副本外跨服队友发送一条新消息，留出冷却时间，检查角色是否在小队发出回复。

0.1.1 同时识别普通小队和跨服小队；退队、换队或跨服成员变化会取消待发回复。发送拦截改为具体原因，便于定位。原始 0.1.0 安装包及文件仍保留，便于回退。

## 关键词规则

| 设置 | 行为 |
|---|---|
| 全局关键词空白 | 自动回复已开启频道中的他人消息 |
| 全局关键词 `小龙，霜璃，AI` | 消息包含任意一个词时回复 |
| 频道勾选“使用独立关键词” | 该频道改用自己的关键词，不再继承全局 |
| 独立关键词空白 | 此频道回复全部他人消息，即使全局填了关键词 |
| 频道关闭 / AI 总开关关闭 | 不请求模型、不回复 |

逗号、中文逗号、分号或换行分隔；匹配是包含关系，忽略英文大小写，不是正则表达式。纯空白或只有分隔符等同于没有关键词。自己的消息和发出的悄悄话不触发。关键词可以填写角色名，从而实现“被叫名字时回复”。

## 支持频道

| 面板选项 | 收到消息后由角色发出 |
|---|---|
| 悄悄话 | `/tell 原发件人@服务器 正文` |
| 说话 | `/s 正文` |
| 小队（含跨服小队消息） | `/p 正文` |
| 团队（联盟） | `/a 正文` |
| 部队 | `/fc 正文` |

这里“团队”指联盟聊天。如果你指的是普通八人队，选择“小队”。插件不改变游戏对禁言、私聊、副本、部队或联盟成员资格的限制；“已提交”表示已交给游戏处理，不等于服务器已送达。不能可靠识别发件人的消息会跳过，绝不猜测私聊对象。

## 模型连接

四组配置分别保存基础地址、协议、模型 ID 和加密密钥。可切换、修改地址，模型名称不写死。

| 配置 | 协议 | 基础地址示例 |
|---|---|---|
| 本机 / OpenAI 兼容 | Chat Completions | `http://127.0.0.1:1234/v1` |
| GPT / OpenAI | Responses | `https://api.openai.com/v1` |
| DeepSeek | Chat Completions | `https://api.deepseek.com/v1` |
| Claude / Anthropic | Messages | `https://api.anthropic.com/v1` |

本机地址是可修改的示例，不代表该端口已有服务。服务需提供 OpenAI 兼容的 `/chat/completions`。模型 ID 填本机服务或云端账户实际提供的名称。本机无需鉴权时密钥留空；需要鉴权时同样可填写。

基础地址填写到 `/v1` 等服务根路径，不要重复添加 `/chat/completions`、`/responses` 或 `/messages`。插件根据协议追加后缀。远程接口使用 HTTPS，本机回环地址支持 HTTP。

GPT 和 Claude 的官方模型通过云端 API 使用。本机连接运行的是你本机服务提供的模型，不会把这些闭源模型下载安装到本机。第三方中转若提供 OpenAI 兼容协议，应把对应配置的“接口协议”改为 Chat Completions。

云端请求会发送触发消息和该会话的有限上下文给所选服务。配置保存于 Dalamud 管理的插件配置目录；API Key 使用当前 Windows 用户的 DPAPI 加密，不写入聊天日志。不在本地保存聊天历史；换 Windows 用户或电脑后需重新填写密钥。

## 自定义与运行规则

- 人设/系统提示词、回复前缀、忽略玩家名单。
- 全局或分频道关键词，五种频道独立开关。
- 回复间隔默认 10 秒（3–120 秒），每分钟请求上限默认 6（1–20）。
- 请求超时默认 45 秒（5–120），输出 token 上限默认 1024（64–8192）。推理模型若只产生推理而没有正文，可提高 token 上限或选择适合短聊天的模型。
- 默认最多保留 6 轮已触发对话；普通频道各自独立，悄悄话按“角色名+服务器”隔离。未触发、忙碌和冷却期间被跳过的消息不写入上下文。
- 默认回复最多 240 个 UTF-8 字节，普通中文汉字通常占 3 字节。超长截断成一条，不多条刷屏。
- 同时只处理一个请求。忙碌、冷却、达到每分钟上限时直接跳过新消息，不排队。短时间多人连续发言时不会每条都回。
- 可选“战斗中暂停”与“仅预览、不发送”。预览模式仍调用模型，生成结果显示在“测试与状态”。
- 关闭、清空上下文、修改配置、退出角色或检测到换区/换小队时，取消旧请求并清空上下文。过场和加载时暂停。
- 生成文字只作为指定频道的正文，不执行模型输出的游戏命令。换行合并、控制符去除、聊天宏尖括号替换；标准 thinking 字段不发送。
- 不带工具调用、战斗操作、移动控制或游戏记忆数据库。

## 命令

```text
/aichat                         打开面板
/aichat on                      开启
/aichat off                     关闭并取消当前回复
/aichat toggle                  切换
/aichat clear                   清空上下文并取消当前回复
/aichat status                  查看状态
/aichat ask party 今天打什么？   手动提问，由角色在小队频道发出 AI 回答
```

手动目标支持 `say`、`party`、`alliance`、`fc`，需要总开关和目标频道都已开启，也受冷却约束。手动提问绕过关键词筛选。悄悄话通过真实收到的消息触发。

## 编译

需要 .NET 10 SDK，以及国服 XIVLauncher 的 Dalamud 开发程序集。项目不引用外部 NuGet 包。

```powershell
.\build.ps1
# 自定义环境：
.\build.ps1 -Dotnet 'D:\tools\dotnet\dotnet.exe' -DalamudLibPath 'D:\XIVLauncherCN\addon\Hooks\dev'
```

脚本依次构建、运行验证，再生成 `dist/0.1.1/AetherChat-0.1.1.zip`。当前任务目录下已准备好便携 SDK，脚本会优先发现它。源码 ZIP 不包含 SDK、游戏程序集或密钥。

## 游戏内验收

1. 加载插件，确认 `/aichat` 中文面板正常、初始总开关关闭。
2. 测试连接成功后，先开启“仅预览”、一个频道和总开关。用另一位玩家发消息，确认面板显示触发者与回复。
3. 填关键词，分别发送命中与不命中的文字；再清空关键词，确认任意普通消息可触发。测试时留出冷却时间。
4. 关闭预览，在小队/私聊实际检查角色发送；逐项检查说话、联盟、部队。测试者需处于相应频道可用的游戏状态。
5. 让两个人依次私聊，确认回复对象正确；角色自己的消息不触发新请求。
6. 生成途中输入 `/aichat off`，确认没有晚到的补发。切图、换小队与重新登录也检查一次。

上面的完整验收清单尚未全部执行；已知用户验证结果见“当前版本与验证范围”。自动测试不会向真实玩家发言。
